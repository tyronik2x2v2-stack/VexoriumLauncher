# VEXORIUM ROLEPLAY Launcher

Windows x64 launcher for the VEXORIUM ROLEPLAY project.

## Build

The GitHub Actions workflow at `.github/workflows/build-installer.yml` builds a self-contained Windows launcher with .NET 8 and publishes it to GitHub Releases.

A new build is started automatically when changes are pushed to the repository, or manually from **Actions → Build VEXORIUM Launcher → Run workflow**.

## Download

The latest launcher is published at:

https://github.com/tyronik2x2v2-stack/VexoriumLauncher/releases/latest/download/VexoriumLauncher.exe

## Game files

The launcher does not distribute the original GTA San Andreas game files. Players must select a compatible, legally obtained PC copy already installed on their computer.

## Version

The current launcher version is stored in `version.json`.
